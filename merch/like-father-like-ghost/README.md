# Like Father, Like Ghost — Merch Capsule

Concept merch direction for the Inpatient Corridors / Break the Grid visual system. See [the concept page](./index.html).

## Design language
- Near-black field
- White institutional typography
- Restrained corridor red (#c0392b)
- Grid / floor-plan geometry
- Ghost treated as an absence/silhouette, not a cartoon
- Keep third-party artist marks, lyrics, recordings, likenesses, and artwork out of sale-ready products until their specific use is confirmed in the source agreement.

## Capsule
1. **LFLG-01 / Corridor Tee** — front wordmark, back corridor diagram.
2. **LFLG-02 / Ghost Notice Tee** — institutional notice treatment with a negative-space ghost.
3. **LFLG-03 / Evidence Hoodie** — small chest mark + large back evidence label.

SVGs are production-vector starting artwork; final garment sizing, screen-print separations, embroidery limits, and rights clearance should be confirmed before manufacture.
