# Claims Register

A quick audit surface for public claims made by this case study.

| Claim | Status | Evidence / boundary |
|---|---|---|
| The current Ren site exposes interactive/music, shop, events and related public surfaces. | **Observed** | Current public Ren site. |
| Creative Deploy documents Sick Boi as a headless Shopify + Sanity project. | **Documented** | Creative Deploy's published Sick Boi case study. |
| Creative Deploy's Sick Boi case study reports client-controlled content workflows and high-traffic drop results. | **Documented** | Creative Deploy's published case study; applies to Sick Boi, not automatically to Ren. |
| Creative Deploy publicly lists Ren Interactive Experience work. | **Documented** | Creative Deploy public work portfolio. |
| Ren's private original brief is known to us. | **Unknown / not claimed** | No private brief available. |
| Ren's exact production architecture is known to us. | **Unknown / not claimed** | No production repository or private architecture record available. |
| Yellow Door demonstrates browser narrative/runtime capability. | **Demonstrated** | Repository source, build workflow and generated artifacts. |
| Rabbit Hole demonstrates portable narrative/content/runtime capability. | **Demonstrated** | Repository source, validation/tests and build artifacts. |
| “UBI: self-employment” is an existing legal benefit or guaranteed income status. | **Not claimed** | It is a project philosophy only. |
| “The Black Hole” is an established entertainment-industry term. | **Not claimed** | It is a project framing term. |
| Actual documented expenses should be recoverable before any proposed remainder is allocated. | **Proposed** | Operating principle, not a statement of legal/tax/benefits treatment. |
| Public servants' total income is universally public record. | **Not claimed** | Jurisdiction-specific legal proposition; requires separate research. |
| The project proves that another vendor failed to deliver. | **Not claimed** | The case study does not make that conclusion. |

## Reading rule

**Documented** means an external source explicitly supports the statement.

**Observed** means the statement describes something publicly visible.

**Demonstrated** means the project itself provides inspectable working evidence.

**Proposed** means an intended principle or future action.

**Unknown / not claimed** means the case study deliberately does not fill an evidence gap with inference.
