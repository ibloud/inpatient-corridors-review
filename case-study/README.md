# 50 Ways to Leave Another — Case Study

This directory is the public-facing case-study layer.

It does **not** replace or rewrite the underlying project. The purpose is to let a reviewer inspect:

- the stated evaluation question;
- working evidence;
- failures and discarded approaches;
- the distinction between demonstrated work and open proposals;
- the proposed transparent-expense compensation principle;
- the project's “UBI: self-employment” framing;
- the “Black Hole” framing as a project term, not an established industry definition.

## Source boundary

The case study should never imply access to a production system, private client brief, private financial records, or legal status that has not been verified.
