# Prototype Readiness and Shared-Benefit Assessment

## Decision

The design contains enough material for an immediate paper playtest and enough system definition to begin a two-player Duet implementation. It is not yet ready for public release or award submission.

## Existing gameplay loop

1. A player chooses an action.
2. Personal Tension and shared System Pressure change.
3. Thresholds transform the board state.
4. Players choose between individual control and cooperation.
5. The game reaches a Control, Continuum, or System Collapse ending.

## What is already specified

- Player count and setup
- Turn actions
- Personal Tension and shared System Pressure
- Pressure tests and Outbursts
- Trauma and Support tokens
- Three escalating board phases
- Six community-care interventions
- Competitive, cooperative, and collapse endings
- Debrief questions
- Safety and consent boundaries

## Minimum Duet implementation decisions

| Gap | Minimum decision |
| --- | --- |
| Initial format | Implement two players first; evaluate four players later |
| Board mapping | Identify current Duet squares used for the Void and player sectors |
| Piece mapping | Map Prime, Warden, Guide, and Traveler to existing Duet pieces |
| State display | Display Tension, System Pressure, Trauma, Support, and current phase |
| Timing | Add a round counter and deterministic phase transitions |
| Consent | Provide an explicit accept/refuse interaction for Clinical Care |
| Shared funding | Let both players contribute Support to Care cards |
| Balance | Playtest thresholds of 6, 8, and 10; treat them as provisional |
| Evaluation | Collect anonymous program feedback, never mental-health profiles |

The first digital prototype should remain a two-player Duet scenario. Four-player support adds networking, interface, and balance complexity without improving the first test of the central mechanic.

## Shared goal

> Build and test an accessible game in which players discover that managing individual behavior cannot repair a system that continually manufactures crisis.

## Conditions for mutual benefit

- Usefulness, consent, and measurable impact precede award positioning.
- Interest, silence, or private review never implies affiliation.
- Chris and Ren make separate participation decisions.
- Rights, compensation, approval, withdrawal, and credit are negotiated before protected material is used.
- The prototype is presented as art and facilitated engagement, not therapy or clinical research.
- Award credit follows completed, verifiable work.

## Readiness summary

- Paper playtest: **ready**
- Two-player Duet implementation: **ready to begin**
- Four-player digital implementation: **defer until the core loop is validated**
- Public release: **not ready; requires testing, partners, permissions, and accessibility review**
- Award submission: **not ready; requires completed work and documented impact**
