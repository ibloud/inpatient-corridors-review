# Training Integration

## Interactive narrative writer pathway

`Inpatient Corridors: The Yellow Door` is used as a hands-on case study in the independent **50 Ways to Leave Another** learning pathway.

The training path focuses on the narrative-writing and production lessons visible in this repository:

- branching choices and convergence;
- story state, variables, and conditional narrative;
- consequence and ending logic;
- controlled narrative revision;
- browser implementation and the Ink-to-runtime handoff;
- accessibility and narrative QA;
- provenance, rights, and production documentation.

Training path:

https://github.com/ibloud/50-ways-to-leave-another/blob/main/docs/interactive-narrative-writer-path.md

## Boundary

This cross-reference identifies an educational use of the repository. It does not change the project's authorship, provenance, rights, participation, collaboration, or approval records. It does not grant permission to reuse third-party material.

The training exercise should work from the repository's original, public-safe narrative and technical materials and should not require protected artist material.

## Suggested learner sequence

1. Read the project README and status/provenance material.
2. Open the Yellow Door Ink source.
3. Map choices, variables, convergence, and endings.
4. Make one controlled narrative change in a learner exercise.
5. Playtest the affected path.
6. Build a small original Ink story using the same concepts.

This document is an educational cross-reference only; it is not a new project requirement.
