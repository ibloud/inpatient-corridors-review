# Loptr Lab ecosystem relationship

This repository remains an independent Inpatient Corridors project. It is not a submodule, branch, or controlled surface of PIXIE Device Stewardship.

## Relationship to PIXIE

`ibloud/pixie-device-stewardship` is a stewardship architecture and research repository. Inpatient Corridors may use its principles as a design reference for consent, provenance, accessibility, reversible actions, and consequence previews.

- **This repository owns:** project direction, game mechanics, narrative, original assets, participation, attribution, and publication.
- **PIXIE owns:** stewardship methodology, evidence boundaries, safety constraints, and device/interaction specifications.
- **PIXIE Holdings may provide:** a separate executable test bench for stewardship patterns.

## Non-negotiable boundary

PIXIE has no authority over this project's files, participants, narrative, publication, or attribution. Any future integration must be explicit, consented, inspectable, and reversible where technically applicable.

No integration should introduce silent inference, secret monitoring, unauthorized file changes, automatic publication, or automatic attribution.

## Intended build path

`Inpatient Corridors -> project-specific consented surfaces -> PIXIE stewardship patterns -> optional PIXIE Holdings test bench`

The relationship is architectural and documentary today. It does **not** claim that a live PIXIE runtime currently controls or integrates with this repository.
